## 📌 프로젝트 개요
* **프로젝트명**: 수성구 스마트 주차정보 시스템 관제 대시보드
* **서비스 링크**: [parking.suseong.kr/dashboard/index](https://parking.suseong.kr/dashboard/index)
* **수행 기간**: 2024.04 ~ 2024.10
* **담당 역할**: RESTful API 연동 및 관제 대시보드 웹 개발
* **도메인**: 공공 스마트시티 주차 관제 및 대시보드 시각화
* **기술 스택**: `Java`, `Spring Boot`, `RESTful API`, `JavaScript`, `HTML5/CSS3`

---

## 🔍 문제 상황 (Problem)
1. **잦은 입출차에 따른 데이터 누락 및 정합성 이슈**:
   * 현장 감지 센서 및 통신망의 일시적 변동, 잦은 입출차 이벤트로 인해 대시보드 상에서 데이터 누락이나 중복 카운트가 발생할 위험이 있었습니다.
2. **반복 갱신으로 인한 브라우저 렌더링 부하**:
   * 주차면 현황이 수시로 갱신될 때마다 전체 DOM 요소를 다시 렌더링하여 화면 깜빡임과 브라우저 메모리 부하가 가중되었습니다.

---

## 💡 해결 방법 (Solution)
1. **RESTful API 응답 표준화 및 데이터 정합성 검증**:
   * 프론트엔드-백엔드 간 API 인터페이스 규격을 표준화하고, 데이터 수신 시 유효성 검증 로직을 거쳐 이상 데이터를 사전 필터링했습니다.
2. **비동기 선별 렌더링(Selective Rendering) 구현**:
   * 전체 화면을 다시 그리지 않고, 변동이 발생한 특정 주차장/주차면 컴포넌트만 감지하여 비동기로 부분 갱신하도록 UI 최적화를 적용했습니다.

---

## 📈 정량적 성과 (Impact)
* 🎯 **실시간 잔여면 데이터 정합성 99% 이상 유지**: 센서 및 입출차 데이터 오차를 최소화하여 시민과 관리자가 신뢰할 수 있는 정보를 제공했습니다.
* 🖥️ **24/365 무중단 관제 안정성 확보**: 메모리 누수 및 깜빡임 없는 선별 렌더링 최적화로 관제센터 다중 디스플레이 환경에서 장시간 안정적 운영을 달성했습니다.
