## 📌 프로젝트 개요
* **프로젝트명**: 대구시 데이터허브 API 신청 및 이용현황 서비스
* **수행 기간**: 2024.07 ~ 2024.12
* **담당 역할**: OpenAPI 신청 프로세스 및 통계 시각화 서비스 개발
* **도메인**: 공공 데이터 허브 플랫폼 및 OpenAPI 연동 관리
* **기술 스택**: `Java`, `Spring Boot`, `OpenAPI`, `Statistics Query`, `RESTful API`

---

## 🔍 문제 상황 (Problem)
1. **대용량 트래픽 통계 집계 시 응답 지연**:
   * 대구시 스마트시티 데이터허브 내 수많은 OpenAPI의 호출 로그가 누적되면서, 관리자 및 사용자가 이용 통계를 조회할 때 복합 집계 쿼리로 인한 응답 딜레이가 발생했습니다.
2. **신청 폼 유효성 검증 누락으로 인한 불필요한 백엔드 예외**:
   * 사용자의 API 키 발급 및 서비스 신청 과정에서 파라미터 유효성 검증이 미흡하여 불필요한 백엔드 예외(Exception)와 리소스 낭비가 초래되었습니다.

---

## 💡 해결 방법 (Solution)
1. **비동기 통계 집계 파이프라인 구축**:
   * 통계 집계 데이터 조회를 비동기 통신 구조로 개편하여 페이지 블로킹 현상을 제거하고, 필요한 데이터만 차트 라이브러리와 매핑하도록 경량화했습니다.
2. **클라이언트-서버 2단계 검증 체계 구현**:
   * 사용자 브라우저 단의 사전 유효성 검증과 서버 단의 비즈니스 룰 검증을 이중으로 적용하여 비정상 입력 요청을 원천 차단했습니다.

---

## 📈 정량적 성과 (Impact)
* 🚀 **통계 집계 조회 응답 속도 대폭 개선**: 대용량 트래픽 통계 차트의 비동기 시각화를 통해 사용자가 새로고침 없이 즉각적인 데이터를 확인할 수 있도록 개선했습니다.
* 🛡️ **백엔드 예외 처리 비용 최소화**: 2단계 검증 체계를 통해 잘못된 입력으로 인한 비정상 트랜잭션을 사전 차단하고 시스템 신뢰성을 확보했습니다.
